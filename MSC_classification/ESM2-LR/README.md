# ESM2-LR

ESM2-LR is a sequence-based classification model for identifying mechanosensitive ion channels (MSCs). This module provides a pretrained Logistic Regression (LR) model for predicting MSCs using protein sequence embeddings generated by ESM2, along with a training pipeline for reproducibility.

## 1. Model Prediction

### 1.1 Required Input Files

Prediction requires an input FASTA file and either precomputed ESM2 embeddings or access to the ESM2 model for embedding generation.

**Input FASTA**

The input FASTA file (`example/input.fasta`) supports both standard and UniProt FASTA formats. Each protein must have a unique accession. Class labels are not required.

**ESM2 Embeddings**

If precomputed ESM2 embeddings are available, place the corresponding `.npy` files in the directory specified by `embedding_dir`. Each .npy filename must match the corresponding protein accession in the input FASTA. The pipeline supports both residue-level embeddings (shape: `L+2 × 1280`, including `<cls>` and `<eos>` tokens) and mean-pooled sequence embeddings.

Alternatively, set `embedding_dir` to `null` to generate embeddings directly from the input FASTA using ESM2 (`esm2_t33_650M_UR50D`). The ESM2 model can be loaded automatically or from a local checkpoint.

### 1.2 Configuration

Prediction parameters are defined under the `predict` section of `config.yaml`:

- `input_fasta`: Input protein FASTA file.
- `esm_model_path`: Path to a local ESM2 model checkpoint. If set to `null`, the model is loaded automatically when embedding generation is required.
- `embedding_dir`: Directory containing existing ESM2 embeddings. If set to `null`, embeddings are generated from the input FASTA.
- `save_embeddings`: Whether to save newly generated token-level embeddings.
- `embedding_output_dir`: Directory for saving newly generated embeddings.
- `output`: Path to the final prediction results.

The pretrained LR classifier is loaded from the model file generated by the training pipeline, located under the directory specified by `train.model_training.output_dir` of `config.yaml`.

### 1.3 Run Prediction

Run the prediction pipeline from the `MSC_classification/ESM2-LR/` directory. 

Input and output paths can be configured directly in `config.yaml` or specified through command-line arguments.

**Option 1. Use settings from `config.yaml`**

Modify the corresponding settings in `config.yaml` as needed, then run:

```bash
python ESM2-LR_predict.py --config config.yaml
```

**Option 2. Specify input and output paths**

```bash
python ESM2-LR_predict.py \
    --config config.yaml \
    --input example/input.fasta \
    --output outputs/predict/predictions.csv
```

Command-line arguments override the corresponding settings in `config.yaml`.


### 1.4 Prediction Outputs

By default, prediction results are saved to `outputs/predict/predictions.csv`. The CSV file contains the following columns:

| Column | Description |
|---|---|
| `AccessionName` | Protein accession from the input FASTA |
| `prediction_probability` | Predicted probability of belonging to the MSC class |
| `predicted_label` | Predicted class (1: MSC; 0: non-MSC), determined by the classification threshold. |

If `save_embeddings` is set to `true`, newly generated token-level embeddings are also saved to the directory specified by `embedding_output_dir`.

## 2. Model Training and Reproduction (Optional)

For reproducibility, the repository also includes the training pipeline used to generate or load ESM2 sequence embeddings, train a Logistic Regression classifier, and evaluate model performance.

**Run the Training Pipeline**

```bash
python ESM2-LR_train.py --config config.yaml
```

The corresponding training parameters and output paths are defined in the `train` section of `config.yaml`.

By default, the trained LR model and evaluation results are saved under `outputs/train/`.
